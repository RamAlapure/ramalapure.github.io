## Problem

Enterprise Java teams need a governed way to integrate LLM agents without ad-hoc HTTP clients and prompt spaghetti.

## What I built

Eliza4J — a Java library enabling AI solutions using BNY’s Eliza AI Agents and LLMs. Model abstraction, agent hooks, and patterns that fit existing Spring services.

## Status

Shipped internally at BNY. Open-source exploration aligned with enterprise constraints.
