## Problem

Big data and integration projects need portable file operations across S3 and SFTP without rewriting adapters.

## What I built

Filesystem library published on Maven Central ([`com.github.ramalapure/filesystem`](https://central.sonatype.com/artifact/com.github.ramalapure/filesystem)) for operations on AWS S3 and SFTP file systems.

## Status

Shipped and published. Useful for ingestion pipelines and file-based integrations.
