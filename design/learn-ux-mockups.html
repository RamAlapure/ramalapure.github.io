Learn · Playground — UX mockups

Proposed child view and parent view for /learn/. The parent view splits into Insights (read-only analytics) and Manage (all operations). Frames are interactive — click tabs, sub-tabs and learner chips.

Child surface — no text-critical path, ≥64px targets Read-only — never mutates state Write — explicit save, toast confirmation

1 · Child view

Changes vs. today: adult controls (language, theme, PIN) collapse into a single ⚙︎ button; a daily-goal ring and a “keep going” card replace the cold 7-card start; subject cards show mastery dots instead of activity counts; the adaptive engine surfaces as one highlighted “try this next” card.

2 · Parent view — Insights (read-only analytics)

One persistent header: learner chips + date range, scoping every panel. Switching learners here keeps the PIN session (today it silently logs the parent out and jumps to the child home). Nothing in this tab writes state — the single exception is Practice now, which deliberately hands the device back to the child.
